# Borrtec — próximos passos para uso profissional

## Etapa 1 — concluída neste pacote
- Removida a credencial administrativa do README.
- Removida a senha pré-preenchida da tela de login.
- Removida a validação de senha administrativa do JavaScript do navegador.
- README atualizado para deixar claro que o projeto ainda é protótipo.

## Etapa 2 — próxima
Criar um backend com banco de dados online e autenticação segura.

O frontend atual poderá continuar sendo aproveitado.

## O que não deve ser feito
- Não colocar senha real dentro de `app.js` ou `index.html`.
- Não colocar senha real no README.
- Não usar `localStorage` como banco de dados de pedidos reais.
- Não publicar dados reais de clientes no repositório.

## Objetivo final
Cliente e administrador deverão acessar o mesmo sistema online, com dados persistidos em banco de dados e autenticação controlada pelo servidor.
