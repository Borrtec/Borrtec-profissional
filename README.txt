BORRTEC - V5

Projeto em preparação para uso profissional.

FUNCIONALIDADES ATUAIS:
- Catálogo de produtos.
- Carrinho e finalização de pedidos.
- Cadastro e login de clientes (versão local/protótipo).
- Informações de entrega e pagamento.
- Painel administrativo (estrutura de interface).

IMPORTANTE:
Esta versão ainda não deve ser usada para receber pedidos reais. Os dados ainda dependem do armazenamento do navegador (localStorage/sessionStorage).

PRÓXIMA ETAPA PARA USO PROFISSIONAL:
- Backend e banco de dados online.
- Autenticação segura de clientes e administradores.
- Senhas armazenadas com hash, nunca no código do navegador.
- Controle de sessão e permissões.
- Dados compartilhados entre celulares e computadores.
- Validação e proteção dos dados de clientes e pedidos.

SEGURANÇA:
Nenhuma senha ou credencial administrativa deve ser publicada neste repositório. As credenciais de produção deverão ser configuradas somente no backend/ambiente seguro.
